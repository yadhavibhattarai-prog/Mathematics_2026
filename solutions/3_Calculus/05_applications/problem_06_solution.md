## Question

### Problem 6. Average Value of a Function

Compute the average value of the function

$$
f(x)=x^2
$$

on the interval $[0,3]$.

Find a point $c\in[0,3]$ for which $f(c)$ is equal to this average value, and interpret the result geometrically.

## Solution

The average value of a function on $[a,b]$ is

$$
\frac{1}{b-a}\int_a^b f(x)\,dx.
$$

Here,

$$
\frac{1}{3-0}\int_0^3 x^2\,dx.
$$

Compute the integral:

$$
\int_0^3 x^2\,dx = \left[\frac{x^3}{3}\right]_0^3 = \frac{27}{3}=9.
$$

Thus the average value is

$$
\frac{1}{3}\cdot 9 = 3.
$$

So the average value is

$$
\boxed{3}.
$$

### 2. Point $c$ with $f(c)=3$

We need a point $c$ such that

$$
c^2=3.
$$

Hence,

$$
c=\sqrt{3}.
$$

Since $\sqrt{3}\in[0,3]$, this is valid.

### 3. Geometric interpretation

The number $3$ is the height of the horizontal line $y=3$ that has the same area under the curve $y=x^2$ over $[0,3]$ as the function itself. In other words, the rectangle of width $3$ and height $3$ has the same area as the region under $y=x^2$ on $[0,3]$.

The point $c=\sqrt3$ is the $x$-value where the curve reaches that average value.
